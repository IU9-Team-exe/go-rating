# Гибридная рейтинговая система для онлайн-игр (например, Го)

Проект реализует REST‑сервис для пересчёта рейтинга игроков по результатам партий, основанный на гибридной системе Glicko‑2 с аномальной коррекцией и векторизацией NumPy.

Подходит для интеграции с игровыми серверами или аналитикой, где вся агрегация по игроку выполняется на клиентской стороне, а сервер предоставляет только расчётную логику.

## 🔁 Обновление рейтинга (API)

### `POST /ratings/update`

Передаёте агрегированные данные игрока и массив сыгранных игр — получаете новые значения рейтинга, RD и волатильности.

### 🔹 Пример запроса:

```json
{
  "rating": 1500,
  "rd": 350,
  "volatility": 0.06,
  "games": [
    { "opp_rating": 1520, "opp_rd": 330, "result": 1.0 },
    { "opp_rating": 1480, "opp_rd": 340, "result": 0.0 }
  ]
}
```

### 🔹 Пример ответа:

```json
{
  "new_rating": 1503.42,
  "new_rd": 349.91,
  "new_volatility": 0.06001
}
```

> 💡 Все значения возвращаются с учётом аномальной коррекции и адаптации неопределённости рейтинга (RD).

## 📚 Теоретическая база

Подробное обоснование и математические выкладки доступны в:

```
doc/formulas.pdf
```

Используемые подходы:
- Glicko‑2 (учёт неопределённости и волатильности)
- Elo (базовая логистическая модель)
- Коррекция "аномалий" (в стиле Российской Федерации Го)
- Байесовская устойчивость к шуму

## 📦 Готово к интеграции

Система отлично подойдёт для:

- игровых серверов (Го, шахматы, онлайн‑турниры),
- аналитических платформ,
- микросервисов с задачами рейтинга.

Просто вызывайте `POST /ratings/update` для каждого игрока после серии партий.
